# ماتریس دسترسی

| نقش                     | دامنه اصلی                                                  |
| ----------------------- | ----------------------------------------------------------- |
| متقاضی/نماینده          | پرونده، سند، پیام، پرداخت و شکایت متعلق به خود              |
| کارشناس ثبتی/نقشه‌بردار | فقط پرونده دارای ارجاع فعال و گزارش متناسب با نقش           |
| پشتیبانی                | تیکت‌ها و پرونده‌های دارای تیکت؛ بدون سند محرمانه و مالی    |
| مالی                    | پرداخت، استرداد و پرونده ارجاع‌شده مالی                     |
| مدیر عملیات             | پرونده‌ها، ارجاع، خدمات، انتقال ارجاع و گزارش عملیاتی       |
| تطبیق                   | شکایت، ریسک، گزارش تطبیق و audit مجاز                       |
| فنی                     | رخداد و وضعیت فنی؛ بدون دسترسی عمومی به اسناد پرونده        |
| مدیر سامانه             | مدیریت کنترل‌شده کاربران و تنظیمات عملیاتی                  |
| ناظر                    | داشبورد و گزارش فقط‌خواندنی؛ بدون تغییر و سند بسیار محرمانه |

منوی پنل برای همه نقش‌ها از یک ماتریس قابلیت مشترک ساخته می‌شود؛ بنابراین همان ماژول‌های پنل مدیریت برای نقش‌های دیگر نیز فقط در صورت داشتن قابلیت مربوط نمایش داده می‌شوند. مسیرهای مستقیم کلاینت و endpointهای API هر دو قابلیت را کنترل می‌کنند. مجوز نهایی همیشه در API بررسی می‌شود؛ پنهان‌کردن گزینه در UI کنترل امنیتی محسوب نمی‌شود.

قابلیت‌های اصلی شامل `dashboard.view`، `applications.view/create/manage`، `workspace.view`، `support.view`، `profile.view` و `management.view` هستند. کنترل‌های ریزتر هر عملیات مانند مدیریت کاربر، backup و مشاهده رخداد علاوه بر قابلیت صفحه با نقش مجاز همان endpoint محدود می‌شوند.
