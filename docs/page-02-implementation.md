# شواهد پیاده‌سازی صفحه ۲

## دامنه الزام

صفحه ۲ طرح، سامانه غیرحضوری امن، تبادل برخط کنترل‌شده، پشتیبانی، گزارش‌دهی نظارتی، حریم خصوصی، قابلیت بازرسی و محدودبودن کارگزاری به پذیرش، بررسی اولیه، تکمیل مدارک، راهنمایی، پیگیری و تشریفات مجاز را الزام می‌کند. همچنین تصمیم نهایی ثبتی، تضمین نتیجه، القای نفوذ، تسریع غیرقانونی و دریافت وجه خارج از ضابطه را منع می‌کند.

## شواهد تکمیلی این تغییر

- خواندن جزئیات و خروجی پرونده در API به مالک پرونده، ارجاع فعال کارشناس، تیکت مرتبط پشتیبانی، پرداخت مرتبط مالی یا نقش نظارتی صریح محدود است؛ نقش فنی به داده پرونده دسترسی ندارد.
- کارشناس ثبتی و نقشه‌بردار در API و UI فقط وضعیت‌های بررسی و تشریفات داخلی را ثبت می‌کنند و امکان ثبت «تبادل با سازمان»، «در انتظار سازمان» یا «خاتمه‌یافته» ندارند.
- ناظر سازمان فقط‌خواندنی باقی می‌ماند و هیچ گزینه تغییر وضعیت در UI یا مجوز تغییر در API ندارد.
- نقش مدیر عملیات یا مدیر سامانه مسئول اقدامات کنترل‌شده تبادل و خاتمه است؛ کنترل بازبینی دوم پرونده‌های پرریسک موجود حفظ شده است.

## آزمون‌های مرتبط

- `server/src/page-02-policy.test.ts`: مالکیت، رابطه مستند کارکنان با پرونده، منع دسترسی نقش فنی و منع تصمیم نهایی توسط کارشناس.
- `client/src/page-02.test.ts`: عدم نمایش اقدامات تبادل/خاتمه برای کارشناس، تفکیک اقدام مدیریتی و نمایش هشدارهای حقوقی.
