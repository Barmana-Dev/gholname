# شواهد پیاده‌سازی صفحه ۸

منبع بررسی‌شده: صفحه ۸ فایل «طرح توجیهی کارگزاری ثبتی (1).pdf» و بخش «۹-۳ تا ۹-۶» در `PDF_LINE_BY_LINE_AUDIT_FA.md`.

## الزامات پوشش‌داده‌شده

- هر ۱۴ گزینه منوی اصلی با همان ترتیب و عنوان سند در ناوبری عمومی قرار گرفت.
- هر ۷ گزینه زیرمنوی خدمات ثبتی و حقوقی و هر ۷ گزینه زیرمنوی خدمات فنی، مهندسی و حدنگاری به صفحه خدمت متناظر متصل شد.
- مسیرهای مستقل دسته خدمات حقوقی و فنی اضافه و داده هر دسته فقط از API عمومی خدمات فعال دریافت می‌شود.
- منو در دسکتاپ، تبلت و موبایل به‌شکل RTL، قابل پیمایش با صفحه‌کلید و بدون خروج افقی ارائه می‌شود.
- دریافت نتیجه پرونده و گزارش مجاز در API به مالک پرونده، کارشناس مأمور، پشتیبان مرتبط، مالی مرتبط و نقش‌های نظارتی مجاز محدود است.
- ثبت شکایت فقط پس از احراز هویت و بر اساس قابلیت نقش در API و UI در دسترس است.
- متن صفحه اصلی وعده قطعی صدور سند، تضمین نتیجه، تسریع غیرقانونی، ارتباط ویژه یا نفوذ اداری ندارد.
