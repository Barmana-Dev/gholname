# معماری سامانه کارگزاری ثبتی

سامانه از سه لایه مستقل تشکیل شده است: رابط React/Vite، API مبتنی بر Express و TypeScript، و MariaDB/MySQL. کلاینت فقط از مسیر `/api` با سرور ارتباط دارد. احراز هویت JWT، کنترل نقش و ثبت audit در لایه API انجام می‌شود و هیچ دسترسی مستقیم مرورگر به پایگاه داده وجود ندارد.

ماژول‌های دامنه شامل هویت/رضایت/OTP/MFA، خدمات، پرونده و ملک، طرف‌های پرونده، اسناد، ارجاع و بازبینی مستقل گزارش، پرداخت و استرداد، شکایت و پیوست، پشتیبانی و تعامل، ریسک، اعلان، صف یکپارچه‌سازی، رخداد امنیتی، backup و گزارش نظارتی است. منوی همه پنل‌ها بر ماتریس قابلیت واحد استوار است و همه عملیات حساس سمت سرور نیز مستقل اعتبارسنجی و مجوزسنجی می‌شوند.

در محیط توسعه، Vite روی 5173، API روی 4000 و پایگاه داده با متغیرهای محیطی اجرا می‌شوند. worker صف سازمان و پایش منابع در فرایند API با claim/idempotency محافظت می‌شوند. در تولید باید TLS، reverse proxy، secret manager، مقصد مستقل backup، scheduler و پایش میزبان فراهم شود.
