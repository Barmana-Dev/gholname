# امنیت و حریم خصوصی

رمز عبور با bcrypt نگهداری می‌شود. JWT، rate limit، Helmet، CORS محدود، query پارامتری، Zod validation، کنترل MIME و امضای فایل، SHA-256، قفل ورود ناموفق و RBAC فعال‌اند. ورود موفق و ناموفق، خروج، تغییر نقش، دانلود/حذف سند و عملیات اصلی در audit زنجیره‌ای ثبت می‌شوند.

اسناد سه سطح `normal`، `confidential` و `highly_confidential` دارند. مالک، نقش سازمانی مجاز و کارشناس ارجاع‌شده بر اساس سطح حساسیت دسترسی می‌گیرند. پرونده بایگانی‌شده محدودتر است. رضایت شرایط استفاده، حریم خصوصی و صحت اطلاعات با نسخه، زمان و IP ذخیره می‌شود.

MFA با TOTP و کدهای بازیابی یک‌بارمصرف فعال است. داده‌های هویتی، ملک و فرم پرونده با AES-256-GCM و IV تصادفی رمز می‌شوند و جست‌وجوی یکتا از blind index استفاده می‌کند. کلید `FIELD_ENCRYPTION_KEY` باید ۶۴ نویسه hex، مستقل از JWT و در secret manager تولید نگهداری شود؛ برنامه در production با کلید نامعتبر بالا نمی‌آید.

رخدادهای نرخ غیرعادی مشاهده/دانلود/ورود ناموفق در `security_events` ثبت و از پنل فنی یا مدیریتی بازبینی می‌شوند. `npm run security:scan` کنترل dependency، typecheck، lint، test، syntax و افشای secret را اجرا و گزارش checksumدار تولید می‌کند. backup رمزنگاری‌شده با کلید مستقل پیاده شده است. TLS، WAF، مدیریت patch میزبان و آزمون نفوذ رسمی همچنان باید در زیرساخت تولید اعمال و مستند شوند.
