یادداشت خدمات: seed فعلی ۹ تعریف قابل استفاده دارد و سه جفت عنوان سند را با subtype پوشش می‌دهد (تفکیک عرصه/آپارتمان، تجمیع/افراز، اصلاح ملک/مندرجات). جدول خدمات و route ایجاد خدمت طوری طراحی شده‌اند که تعریف‌های مستقل بعدی بدون بازنویسی هسته اضافه شوند؛ این mapping به‌عنوان ۱۲ ردیف مستقل DB ادعا نمی‌شود.

## اعتبارسنجی انجام‌شده

- schema و seed روی MariaDB سازگار با XAMPP: ۴۲ جدول canonical، ۱۱ نقش و ۹ خدمت؛ جدول `schema_migrations` و ۱۳ migration نیز توسط setup/validation مدیریت می‌شوند (۴۳ جدول در validation نهایی).
- مسیر ثبت‌نام، تشکیل پرونده، آپلود PDF، ارسال، ارجاع، بررسی مدرک، گزارش کارشناسی، ریسک، پیام و اعلان روی DB ایزوله محلی End-to-End اجرا شد؛ XAMPP daemon اصلی و providerهای رسمی باید در مقصد جداگانه تأیید شوند.
- مسیر پشتیبانی و شکایت: ثبت، کد رهگیری، پاسخ و خاتمه
- تشکیل پرونده جداگانه برای هر ۹ خدمت
- کنترل امن غیرفعال‌بودن پرداخت و API واقعی تا دریافت دسترسی رسمی
- smoke رابط و health زنده در این checkout تأیید شد (HTTP 200 روی ۵۱۷۳ و `database=connected` روی API)؛ مرور بصری دستی staging، PSP و Registry رسمی باید در مقصد تکرار شوند.
